# Pre-Procedure Worklist — dashboard mockup

A static mockup of a pre-operative care-coordination worklist: patients ranked
by how likely they are to cancel, no-show or reschedule, with the reason in
plain language and the next action one click away.

**Live:** https://denuosource.github.io/preop-worklist-mockup/

## All data here is fabricated

Every patient, surgeon, procedure, identifier and metric in this repository is
generated by `data/generate_mock.py`. Nothing comes from a real patient,
practice or database.

## What it shows

**Worklist** — two windows, D−3 (the working list, where most barriers can
still be cleared) and D−1 (do today). Each patient carries a 0–100 risk score
scored from tasks alone:

| Input | Weight |
|---|---|
| Overdue load — hours past due × criticality (3.0× critical, 1.5× important, 0.5× routine) | 65% |
| Share of critical tasks still open | 35% |

Every task is tagged twice, which is what makes the ranking work:

- **Criticality** — does the procedure still go ahead safely without it? Drives
  the ranking, so one overdue "stop blood thinners" outranks three overdue
  "watch the prep video".
- **Barrier category** — what kind of problem is it? Drives routing: which
  channel actually clears it.

**Patient 360** — a slide-over per patient: score breakdown, open barriers, and
the overdue task list filterable by criticality and by barrier category.

**Measured Impact** *(temporarily hidden from the nav — page and data are
still in the build, just not linked to right now)* — resolution rate by
channel, and a channel-by-barrier matrix. Medication and financial blocks
need a phone call (29–38% clear by text); transport, admin and education
clear on the cheapest channel.

**Done / watchlist** — row actions recording that a coordinator acted. They
deliberately do not move the task counts, which track the underlying data.

## Running it

Needs a web server — the page fetches `data/worklist.json`, which `file://`
blocks.

```bash
python3 -m http.server 8080
```

To reshuffle the cohort:

```bash
cd data && python3 generate_mock.py
```
